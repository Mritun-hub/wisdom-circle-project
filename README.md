# 📖 About the Project

**Wisdom Circle** is a community platform that allows users to share life lessons, experiences, and wisdom anonymously.

The goal is to create a place where people can learn from each other's real-life experiences.

---

# 🚀 Features

✅ Anonymous life lesson sharing
✅ User login & signup system
✅ Modern responsive UI
✅ Real-time posts feed
✅ Full-stack architecture
✅ MongoDB database integration

# ⚙️ Installation & Setup

### 1️⃣ Clone the repository

git clone https://github.com/Mritun-hub/wisdom-circle

---

### 2️⃣ Install backend dependencies

cd server
npm install

Run backend:

npm run dev

Server will run on:

http://localhost:5000

---

### 3️⃣ Install frontend dependencies

cd client
npm install

Run frontend:

npm run dev

Frontend will run on:

http://localhost:5173
